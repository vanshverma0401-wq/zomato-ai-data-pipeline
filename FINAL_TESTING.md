# Run and verify the project

Follow [the portable setup and testing guide](docs/SETUP.md). It contains the required configuration, Snowflake/AWS setup order, offline checks, explicit credit confirmation, manual DAG commands, and both app demonstrations.

Live AI is locked until you provide your own organization, project, verified credit expiry and an unexpired confirmation of usable promotional credit without paid fallback. The repository contains no API key, Snowflake private key, dataset, live balance, or armed credit receipt.

Run the offline tests first. A successful offline suite does not establish warehouse access, model availability, correct cloud grants, or end-to-end model quality. Capture those outcomes from your own explicit live run before making those claims.
